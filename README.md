## 📖 Overview
A full-stack, production-grade application engineered to streamline bulk client outreach and supplier communications. Designed for high-volume networking, this dashboard integrates constrained AI for precise content generation, secure local session management, and a robust cloud database architecture. 

<br/>

## 🛠️ Technology Stack
*   **Frontend:** React.js, HTML5, Advanced CSS3
*   **Backend:** Python, FastAPI, SQLAlchemy
*   **Database:** PostgreSQL (Supabase) via IPv4 Supavisor Pooler
*   **AI Integration:** Groq API (Llama Models)
*   **Deployment:** Vercel (Client Edge CDN) & Render (Web Service)

<br/>

## ✨ Core Architecture & Security
*   **Constrained AI Generation:** Advanced system prompts and rigid token constraints (max_tokens=25) strictly regulate the AI, preventing prompt hallucinations and mitigating API resource exhaustion.
*   **Database Integrity:** Built on a permanent PostgreSQL cloud architecture, utilizing SQLAlchemy's parameterized queries to automatically neutralize SQL injection vectors.
*   **Network Resilience:** Implements specialized connection poolers (pgbouncer logic) to seamlessly bridge IPv4 server environments with modern IPv6 database hosts, eliminating routing failures.
*   **Secure Session Management:** Features lightweight, stateless frontend authentication coupled with manual secure termination controls (System Logout).
